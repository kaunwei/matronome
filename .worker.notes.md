# Worker Repository Notes & Quirks

This file contains repository-specific quirks, build flags, and tips discovered by the Worker AI across tasks.

## Build & Test Quirks
- For Python modules: Use standard library `python3 -m unittest discover tests` or `python3 -m unittest tests/test_<name>.py`.
- For C/C++ modules: Prefer incremental build with `cmake --build build -j$(nproc)` or `ninja -C build`.
